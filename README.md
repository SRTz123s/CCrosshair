## О программе

**Custom Crosshair** — десктоп-приложение для Windows, которое рисует собственный прицел поверх всех окон и программ. Прицел всегда находится в центре экрана, не перехватывает ввод и не мешает работе с приложениями под ним.

Интерфейс выполнен в стиле Windows 11 (Fluent Design / WinUI 3) с поддержкой тёмной и светлой темы, эффекта **Mica** и смены акцентного цвета. Программа полностью переведена на **русский и английский**.

## Возможности

### Прицел
- **8 параметров настройки** с живым предпросмотром:
  - **Размер** — длина линий (10–250 px)
  - **Зазор** — отступ линий от центра (1–40 px)
  - **Толщина** — ширина линий (1–20 px)
  - **Прозрачность** (10–100 %)
  - **Точка в центре** и её размер (1–20 px)
  - **Обводка** — чёрный контур вокруг линий и точки (0–10 px)
  - **Цвет** — любая палитра (Fluent ColorDialog)
- Чёткая отрисовка по сетке пикселей без сглаживания — линии в 1 px выглядят тонкими и контрастными
- Оптический центр линий всегда совпадает с центром экрана (учтён сдвиг пера при чётной толщине)

### Оверлей
- Окно прицела всегда поверх всех окон, бескаркасное и прозрачное
- Не активируется, не перехватывает фокус, не видно в Alt+Tab
- Системная тень вокруг оверлея отключается через DWM

### Программы
- Режим **«Только в выбранных программах»**: прицел показывается лишь в отмеченных окнах
- Автоматическое отслеживание активного окна (100 мс) и скрытие прицела в невыбранных приложениях
- Список запущенных окон с PID и кнопкой обновления

### Профили и обмен настройками
- **Код прицела** — настройки кодируются в компактную строку `CH1:...`, которую можно скопировать и поделиться (контрольная сумма CRC32)
- **Экспорт / импорт** всех настроек программы (прицел + интерфейс + горячие клавиши + список программ) в JSON-файл

### Интерфейс и система
- Тема: **Авто** (следует за Windows) / тёмная / светлая
- **Mica** — полупрозрачный фон окна (Windows 11)
- **Акцент интерфейса**: цвет прицела или системный акцент Windows
- **Горячие клавиши** — настраиваемые сочетания
- Язык: **русский / английский**
- Настройки сохраняются в `crosshair_settings.json` (автосохранение с задержкой 600 мс)
- Показ прицела при запуске (опционально)

## Установка

Требуется **Windows 10 / 11** и **Python 3.10+**.

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/yourusername/custom-crosshair.git
cd custom-crosshair

# 2. Создайте виртуальное окружение (рекомендуется)
python -m venv .venv
.venv\Scripts\activate

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Запустите
python main.py
```

## Использование

1. Запустите `python main.py`.
2. На странице **«Прицел»** настройте размер, зазор, толщину, прозрачность, точку и цвет — изменения сразу видны в предпросмотре.
3. Нажмите **«Показать прицел»** или горячую клавишу `Ctrl+Shift+C` — прицел появится в центре экрана.
4. На странице **«Программы»** включите режим «Только в выбранных программах» и отметьте приложения, в которых прицел должен быть виден.
5. На странице **«Настройки»** измените тему, язык, акцент и горячие клавиши.
6. На странице **«Профили»** скопируйте код прицела, чтобы поделиться настройками, или экспортируйте всё в JSON.

### Горячие клавиши

| Действие | По умолчанию | Описание |
| --- | --- | --- |
| Показать / скрыть прицел | `Ctrl+Shift+C` | Быстрое включение и выключение прицела |
| Сохранить настройки | `Ctrl+Shift+S` | Записать настройки в файл |
| Сбросить настройки | `Ctrl+Shift+R` | Вернуть значения по умолчанию |

Все сочетания настраиваются на странице «Настройки» → вкладка «Горячие клавиши».

### Код прицела

Код прицела — это компактная строка с закодированными параметрами, которую можно переслать другому пользователю:

```
CH1:<base64url(json)>:<CRC32>
```

Скопировал код → вставил в поле на странице «Профили» → применил — прицел настроен.

## Файл настроек

Все параметры хранятся в `crosshair_settings.json` рядом с программой:

```json
{
  "size": 30,
  "color": "#00FF00",
  "opacity": 100,
  "thickness": 2,
  "gap": 5,
  "dot": true,
  "dot_size": 3,
  "outline": 0,
  "selected_processes": [],
  "theme": "system",
  "language": "ru",
  "follow_crosshair_accent": true,
  "follow_windows_accent": false,
  "show_on_startup": false,
  "mica": true,
  "hotkeys": {
    "toggle": "Ctrl+Shift+C",
    "save": "Ctrl+Shift+S",
    "reset": "Ctrl+Shift+R"
  }
}
```

| Ключ | Значения | Описание |
| --- | --- | --- |
| `size` | `10` – `250` | Длина линий прицела |
| `color` | HEX-цвет | Цвет линий |
| `opacity` | `10` – `100` | Непрозрачность прицела, % |
| `thickness` | `1` – `20` | Толщина линий |
| `gap` | `1` – `40` | Зазор от центра до линий |
| `dot` | `true` / `false` | Показывать точку в центре |
| `dot_size` | `1` – `20` | Диаметр центральной точки |
| `outline` | `0` – `10` | Толщина чёрной обводки |
| `selected_processes` | список заголовков окон | Программы, в которых виден прицел |
| `theme` | `system` / `dark` / `light` | Тема интерфейса |
| `language` | `ru` / `en` | Язык интерфейса |
| `follow_crosshair_accent` | `true` / `false` | Цвет прицела как акцент интерфейса |
| `follow_windows_accent` | `true` / `false` | Акцент из Windows |
| `show_on_startup` | `true` / `false` | Показывать прицел при запуске |
| `mica` | `true` / `false` | Эффект Mica (Windows 11) |
| `hotkeys` | объект | Горячие клавиши |

## Как это работает

- **Оверлей** (`core/crosshair_window.py`) — бескаркасное окно `QWidget` с атрибутами `WindowStaysOnTopHint`, `FramelessWindowHint`, `Tool`, прозрачным фоном (`WA_TranslucentBackground`) и отключённой активацией (`WA_ShowWithoutActivating`).
- **Отрисовка** (`core/crosshair_renderer.py`) — единая функция рисует прицел и в оверлее, и в предпросмотре: линии без сглаживания, точно по сетке пикселей, с компенсацией полупиксельного сдвига пера при чётной толщине.
- **Отслеживание окон** (`core/windows_api.py`) — через `GetForegroundWindow` / `EnumWindows` / `GetWindowThreadProcessId`; системная тень оверлея убирается через `DwmSetWindowAttribute`.
- **Состояние** (`ui/state.py`) — единый источник данных `AppState` связывает страницы интерфейса и оверлей через сигналы Qt.
- **Тема** — режим применяется через `qfluentwidgets` до создания окна, чтобы избежать мигания при запуске.
- **Проверка активного окна** — таймер каждые 100 мс скрывает прицел, если активное окно не входит в выбранные программы.
